Recommended Technology Stack
The Lutterodt Renaissance — Phase 1 MVP

For this project, I'd recommend a modern, scalable, AI-ready stack that minimizes operational overhead while supporting future growth into a full digital legacy platform.

1. Frontend
Technology	Purpose	Why
Next.js 15+	Application Framework	Excellent SEO, performance, server rendering, and App Router support
React 19	UI Framework	Industry standard with a large ecosystem
TypeScript	Type Safety	Reduces bugs and improves maintainability
Tailwind CSS 4	Styling	Fast development and consistent design system
shadcn/ui	UI Components	Accessible, customizable, production-ready components
Framer Motion	Animations	Elegant page transitions and interactions
Lucide React	Icons	Clean, lightweight icon library
Swiper.js	Carousels	Timelines, galleries, featured stories
2. Backend
Technology	Purpose
Supabase	Backend-as-a-Service
PostgreSQL	Primary relational database
Supabase Auth	Authentication
Supabase Storage	Photos, videos, PDFs
Supabase Realtime	Future live features

This provides a robust backend with minimal infrastructure management.

Why this stack?

This combination emphasizes speed, maintainability, and future scalability:

Rapid MVP delivery with minimal DevOps.
Excellent performance for SEO and public storytelling.
Low operating costs while the platform grows.
Strong security and role-based access control.
A clear upgrade path to advanced AI, genealogy, and collaboration features without requiring a major architectural rewrite.
